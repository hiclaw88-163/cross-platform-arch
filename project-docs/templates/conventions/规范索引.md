# {project} 开发规范 · 索引

> **关系**：本目录 = {project} 项目覆写与落地约定，**自包含**。
> 冲突时：**本目录 + 架构规划文档优先**于通用模板默认值。

## 使用前必读

1. 先读 [`00-项目配置.md`](./00-项目配置.md)（唯一变量入口，模板中的 `{变量}` 由此替换）
2. 按任务类型在下表加载对应文档
3. 遵守文中 ❌ 禁止项；生成代码前过检查清单

## 快速路由

| 你要做什么 | 读哪篇 |
|-----------|--------|
| 起模块 / 起服务名 / 命名空间 | `01-命名空间.md`（按项目实际编号填充） |
| 写代码 / 起类名 / 分层 | `02-*.md` 系列规范 |
| 设计 / 改接口、错误码 | `03-*.md` |
| 建表、改字段、索引 | `04-*.md` |
| 生成任意 git 提交信息 | `08-提交信息规范.md`（骨架自带，格式 `<type>:[<需求单号>]: <中文主题>`，钩子强制校验） |
| 分支、Code Review | 后续按项目实际编号追加（避免与 `08-` 冲突） |

（上表按项目实际 conventions 编号填充；编号稳定后不重排）
